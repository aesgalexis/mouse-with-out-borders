Windows x64 preview making the application interface consistently English.

- The main window and notification-area menu now use **Remap keys...**.
- The editor uses **Enable key remapping**, **Input key**, **Output key**, **Add**, **Change selected**, **Remove**, **Cancel** and **Save and apply**.
- Key-remapping help, presets, status, validation and save/enable failure messages are in English.
- Keyboard-layout-specific OEM keys retain their printable symbols. Localized descriptive names supplied by Windows are replaced by symbols or English OEM fallback labels.
- Current installation instructions and documentation match the English controls.

Includes all v0.1.8 receiver-minimize, focus, cursor/button recovery and input-thread improvements. Existing pairing, preferences and saved key mappings are retained; the protocol is unchanged.

Downloads: per-user installer, self-contained portable ZIP and SHA-256 checksums.
