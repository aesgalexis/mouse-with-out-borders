Windows x64 preview including the startup, reconnection and administrator-window improvements from 2026-10-24.

- **Start with Windows** and **Connect / listen automatically** are enabled by default. Saved pairing resumes in the notification area after sign-in, with automatic retries while the other PC is offline.
- Startup and automatic-connection preferences are saved; explicit opt-outs are retained. Incomplete pairing remains editable instead of starting a failed connection.
- Use **Restart as administrator...** in the main window or tray menu on the PC displaying Task Manager or another elevated window. Approve UAC with that PC's local mouse/touchpad. Pairing is saved and active sharing resumes after restart.
- Cancelling UAC or a failed restart preserves the original app and connection. Administrator mode is shown explicitly and applies to the current session; normal Windows startup remains unelevated.
- Connection failures now show retry status instead of incorrectly reporting a mouse-input failure.

Includes all previous mouse sharing, hidden inactive cursor, dark interface, icon, updater and local keyboard remapping changes. The two-way mouse protocol remains compatible with 0.1.3–0.1.5. Pairing and settings are retained.

UAC prompts and locked/secure desktops still require a local device. Automated transport, input, keyboard, updater, startup/elevation UI and installer checks run before publication. Physical two-PC interaction and actual sign-out/reboot remain manual acceptance checks.

Downloads: per-user Windows installer, self-contained portable ZIP and SHA-256 checksums.
