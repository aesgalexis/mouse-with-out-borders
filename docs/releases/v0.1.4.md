Windows x64 preview improving cursor visibility, icons and the dark interface.

- The PC you leave hides its parked cursor, in both directions. Local mouse input, return, stopping and disconnection restore it. The cursor window does not activate or change the Windows cursor scheme.
- The app loads its icon directly for the window, tray and header. Setup installs a versioned icon and updates existing desktop shortcuts targeting MWB, including renamed shortcuts, to avoid stale cached icons.
- Dark tray menus, selectors, checkboxes and buttons use explicit readable colors, including hover and disabled states. Smaller screens can scroll the window.

Install 0.1.4 on both PCs for the complete visual improvements. It retains the two-way protocol and pairing settings from 0.1.3. Versions 0.1.2 and earlier still require updating both PCs.

Download `MouseWithOutBorders-0.1.4-Setup.exe` or the portable ZIP. SHA-256 checksums are included. The updater in 0.1.3 can install this release.

Automated connection/input, updater/UI and installer/shortcut migration checks run before publishing. Native cursor transparency, focus preservation and restoration are also verified locally. Physical two-PC hardware acceptance remains necessary.
