Windows x64 preview with clipboard sharing and input consistency fixes.

- Optional clipboard sharing in both directions: plain text up to 1 MiB, or up to 20 regular files and 25 MiB total per copy. Enable **Share clipboard** on both PCs. Folders, links, images and rich formatting are excluded.
- Clipboard payloads use session-bound AES-GCM encryption, acknowledged chunks and SHA-256 verification. Mouse traffic takes priority. New copies and disconnections cancel unfinished transfers; received files remain available for pasting after MWB exits.
- Remapped keys consume the original input, including printable/OEM keys, modifiers and repeats. Reentrant input and failed injection no longer forward the original key or retain stale pressed state.
- Desktop shortcut creation defaults to unchecked during installation and updates. Deleted shortcuts stay absent; existing shortcuts are preserved.
- Concise English controls with redundant notes, examples, subtitles and presets removed.

Includes the earlier mouse handoff, receiver-minimize, focus and cursor/button recovery fixes. Pairing, preferences and saved mappings are retained. Older two-way versions keep mouse compatibility; clipboard sharing requires 0.1.10 on both PCs.

Use **Check & install updates** in an existing 0.1.3-or-newer app, or download the per-user installer. A self-contained portable ZIP and SHA-256 checksums are also included. Physical two-PC acceptance remains pending; automated Windows builds, transport, clipboard, keyboard, UI and installer checks run before publication.
