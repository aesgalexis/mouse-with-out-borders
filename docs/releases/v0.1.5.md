Windows x64 preview adding local keyboard remapping.

- Open **Reasignar teclas...** from the main window or tray menu.
- Choose **Tecla de entrada** (the key you press) and **Tecla de salida** (the key to send), click **Añadir**, then **Guardar y aplicar**. The entire setup works with the mouse; Enter and Backspace are not required.
- Edit or remove mappings, disable them, or use the optional F11 → Backspace / F12 → Enter preset. No keys change until you save your own configuration.
- Mappings persist and resume when MWB starts, including in the tray and without a mouse-sharing connection. Editing temporarily pauses remapping; cancelling restores the previous configuration.
- Repetition, swaps, shared targets and held-key cleanup are handled. Remapping never sends keystrokes over the network or records typed text.

MWB must remain running. Elevated applications require MWB at the same privilege level; secure Windows screens and keyboard firmware-only keys are outside the remapper. This is key-to-key remapping, not shortcut-to-text expansion.

Includes the 0.1.4 mouse/cursor/icon/interface improvements. Existing mouse pairing and settings are retained. The 0.1.3/0.1.4 two-way mouse protocol is unchanged.

Connection, mouse, remapping, updater/UI and installer tests run before publication. A native keyboard check also verifies Enter/Backspace and repeat with generated output intercepted before it can reach user windows.
