Windows x64 preview fixing the intermittent jump to the centre of the PC with the mouse when returning across the shared edge.

- Native cursor placements now carry an ownership tag. Delayed central parking moves and remote movements from an earlier owner are discarded instead of overwriting the new position.
- The returning cursor appears beside the shared edge at the height where it left the other PC. Old-anchor input stays suppressed until Windows processes that placement, and the parked pointer stays hidden until then.
- Local mouse takeover cancels old remote placements. Movement and clicks within the current ownership retain their order. Closing the session restores cursor visibility.

Regression tests cover delayed placements in both layouts and on both PCs. An optional native Windows test reproduces the centre jump with the previous unguarded hook behavior and verifies that the corrected hook retains the edge and resumes local movement. It does not inject clicks and restores the original cursor position afterward.

Includes all v0.1.6 startup, automatic reconnection and administrator-restart improvements. Pairing, preferences and the two-way protocol remain compatible. Actual two-PC hardware acceptance remains a manual check.

Downloads: per-user installer, self-contained portable ZIP and SHA-256 checksums.
