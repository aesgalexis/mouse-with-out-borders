Windows x64 preview addressing receiver freezes when minimizing MWB and inconsistent focus during mouse handoffs.

- Mouse capture, remote packet handling and input injection now run on their own input thread. The main MWB window can be minimized, dragged or hidden without blocking remote movement and button releases.
- Pointer parking windows are created and destroyed outside low-level hooks, with native non-activating visibility changes. Crossing between PCs does not deliberately activate or restore MWB.
- Missing cursor-placement acknowledgements recover after 250 ms. Expired placements are discarded, so a late centre/edge move cannot overwrite recovered local movement.
- Button state is updated before Windows injection to tolerate reentrant callbacks. Failed releases stop the transition and trigger cleanup instead of silently continuing with a pressed button.
- Pairing/reconnecting preserves buttons already held locally; a new click clears obsolete release suppression. Input backlogs have explicit limits and an input worker failure closes the peer for recovery.
- Shutdown restores the cursor while the hook is still available to reject stale placements. Deferred native/window errors are contained.

Regression suites cover input while the main UI is blocked, repeated startup/shutdown, cursor timeouts, reentrant button injection, held drags and stalled network peers. The optional native Windows check minimizes an owned MWB window using remote input, then exercises repeated handoffs while the main UI stays blocked and checks foreground focus.

Includes all previous updates, local keyboard remapping, startup/reconnection and administrator-mode features. Pairing, preferences and the protocol remain compatible. Install on both PCs. Physical two-PC acceptance still needs checking on the user's hardware.

Downloads: per-user installer, self-contained portable ZIP and SHA-256 checksums.
