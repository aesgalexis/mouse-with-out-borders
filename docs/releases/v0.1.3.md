Windows x64 preview with two-way mouse sharing, manual updates and a new minimal icon.

- New flat blue cursor crossing an open screen edge, with a transparent background and Windows icon sizes from 16 to 256 pixels. Applied to the application, tray, shortcuts and Setup.
- Share mice and built-in touchpads from either PC after one pairing.
- Fix the unintended desktop context menu when returning across the shared edge by releasing only buttons actually pressed by MWB.
- Check and install newer GitHub releases manually from the app, with download progress, SHA-256 verification and automatic restart.
- Setup automatically closes MWB before updating, including when it is in the notification area, and retains pairing and preferences.

**Update both PCs to 0.1.3.** Version 0.1.2 uses an incompatible one-way protocol. Existing eight-character pairing codes are retained.

Download `MouseWithOutBorders-0.1.3-Setup.exe` for installation, or the portable ZIP. `SHA256SUMS.txt` contains the checksums for both downloads.

Automated Windows compilation, connection/input, updater/UI and installation/upgrade/restart checks run before publishing. Physical two-PC USB/Bluetooth/touchpad acceptance testing remains necessary.
